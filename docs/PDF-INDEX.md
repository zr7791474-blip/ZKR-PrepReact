## Notes de correspondance

- **Pages 4 à 219** : 84 fiches réparties sur les chapitres 1 à 8, dans l'ordre du PDF.
  Les leçons sans extrait de code n'ont pas de démonstration, conformément au contenu du PDF.
- **Exercice JSX (p. 119–121)** : les solutions du PDF sont des images ; le code affiché est
  une reconstitution fidèle à l'énoncé, signalée dans la fiche.
- **Exercices 1 à 3 des pages 17 à 42** : le PDF ne donne pas de corrigé imprimé ; la
  démonstration calcule le résultat à partir de l'énoncé et l'indique.
- **Exercice 1 (p. 221–224)** : la leçon de la page 221 parle d'un composant classe, mais
  la solution de la page 223 utilise un composant fonctionnel avec `useState` et `useEffect`.
  Les deux approches sont présentées.
- **Exercice 3 / Quiz** : les pages 242 à 245 contiennent l'exercice ; les pages 245 et 246
  contiennent les trois questions du quiz. Les deux fiches se chevauchent volontairement sur
  la page 245.
- **Exercice 4** : page 308. Le PDF ne fournit pas de corrigé ; la fiche conserve la consigne,
  les étapes, un point de départ à compléter et une checklist, sans solution inventée.
- **Exemple CRUD Toolkit** : pages 313 à 317. Les corrections des deux bugs du PDF
  (identifiants dupliqués et état `nom` partagé) sont signalées dans la fiche.
- **Exemple createAsyncThunk** : pages 318 à 322. La fiche corrige l'affichage de
  `action.error` en utilisant `action.error.message`.
